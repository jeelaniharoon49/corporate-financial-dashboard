# Corporate Financial Dashboard (SQL + Power BI)

## Overview

This project analyzes corporate financial performance using SQL and Power BI. A financial sales dataset containing 700 records was imported into MySQL, cleaned using SQL queries, and visualized through an interactive Power BI dashboard.

The dashboard provides insights into revenue, profit, product performance, country performance, and business segments.

---

## Project Workflow

1. Downloaded financial sales dataset from Kaggle.
2. Imported dataset into MySQL.
3. Cleaned and transformed financial fields using SQL.
4. Performed business analysis using SQL queries.
5. Connected cleaned data to Power BI.
6. Built an interactive dashboard with KPIs and visualizations.

---

## Dashboard Features

- Revenue KPI
- Profit KPI
- Profit Margin KPI
- Units Sold KPI
- Revenue by Country
- Revenue by Segment
- Product Performance Analysis
- Revenue Trend Analysis
- Interactive Filters and Slicers

---

## Key Insights

- Government segment generated the highest revenue.
- Paseo was the top-performing product by both revenue and profit.
- United States contributed the highest overall revenue.
- Revenue increased significantly in 2014 compared to 2013.
